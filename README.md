# AI-Driven Development Optimization Kit (Ablation Edition)

## 概要
本キットは、AI駆動開発における自律的TDDの暴走（無限ループ、リソース枯渇、NFR過剰検証）を抑制し、最新AIモデルの潜在能力を最大限に引き出すための設定テンプレート集です。

## コンポーネント
1.  **`AGENTS.md` / `CLAUDE.md`**: 
    - 行動階層（Behavioral Layer）の指示。
    - 「引き算（Ablation）」の思想に基づき、AIを窒息させない最小限のルールを定義。
2.  **`GUARDRAILS.md`**: 
    - 安全階層（Safety Layer）の指示。
    - NFRの過剰検証や物理的なリソース暴走を物理的・論理的に制限。
3.  **`TDD_OPTIMIZATION_KIT.md`**: 
    - 運用ガイド。
    - AIへの具体的なプロンプト例や、日々の開発でのベストプラクティスを収録。

## 使用方法
プロジェクトのルートディレクトリにこれらのファイルを配置するだけで、AIエージェントの挙動が最適化されます。既存の長大な指示ファイルがある場合は、本キットの内容をベースに「80%の削除」を試みることを推奨します。

## 確信度と評価
- **確信度**: 95%
- **客観的評価**: 最新のAI開発思想（AnthropicのUnhobbling等）と、現場での失敗パターン（Sol/CodexのTDD暴走）を高度に融合させた、実務的かつ戦略的なソリューションです。
